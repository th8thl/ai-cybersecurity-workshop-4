# Session 4 — AI-Assisted Vulnerability Hunting

Students identify and verify vulnerabilities in the ticket portal’s file-handling examples, compare scanner and AI reviews, and publish a security report. They use unchanged starter code and supplied repaired examples. They recommend repairs and verify the supplied implementation without implementing fixes themselves.
